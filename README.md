# Conselho do Tarot do Dia

Um site interativo de tarot desenvolvido com HTML, CSS e JavaScript.

O projeto permite que a pessoa receba uma carta do tarot por dia, leia um conselho reflexivo e explore o baralho completo com 78 cartas, incluindo Arcanos Maiores e Menores.

## Funcionalidades

- Carta do dia salva no navegador
- Sorteio livre de cartas
- Baralho completo com 78 cartas
- Arcanos Maiores e Menores
- Filtros por tipo de carta e naipe
- Imagens geradas para cada carta
- Conselhos e perguntas de reflexão
- Suporte a dois idiomas: Português e Inglês
- Alternância entre modo claro e modo escuro
- Layout responsivo para desktop e mobile
- Armazenamento local com LocalStorage

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- LocalStorage
- GitHub Pages

## Objetivo do Projeto

Este projeto foi criado com o objetivo de praticar desenvolvimento front-end por meio de uma interface visual, interativa e responsiva.

Durante o desenvolvimento, foram trabalhados conceitos como:

- Estruturação de páginas com HTML
- Estilização com CSS
- Responsividade
- Manipulação do DOM com JavaScript
- Criação dinâmica de elementos
- Uso de LocalStorage
- Implementação de modo claro e escuro
- Internacionalização básica com suporte a Português e Inglês
- Organização de dados para exibição de cartas e conteúdos

Além da prática técnica, o projeto busca oferecer uma experiência mais sensível e reflexiva, permitindo que cada pessoa tire uma carta, leia uma mensagem e explore o tarot de forma leve e visual.

## Como Usar

1. Abra o site.
2. Veja a carta do dia.
3. Leia o conselho e a pergunta de reflexão.
4. Use o botão de sorteio livre para tirar outras cartas.
5. Explore o baralho completo.
6. Use os filtros para visualizar Arcanos Maiores, Paus, Copas, Espadas ou Ouros.
7. Alterne entre Português e Inglês pelo seletor de idioma.
8. Use o botão de tema para alternar entre modo claro e escuro.
