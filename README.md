# Conselho do Tarot do Dia

Um site interativo de tarot feito com HTML, CSS e JavaScript.  
O projeto mostra uma carta do tarot por dia, traz um conselho reflexivo e permite explorar o baralho completo com Arcanos Maiores e Menores.

## Funcionalidades

- Carta do dia salva no navegador
- Sorteio livre de cartas
- Baralho completo com 78 cartas
- Arcanos Maiores e Menores
- Filtros por naipe: Paus, Copas, Espadas e Ouros
- Imagens geradas para cada carta
- Modo claro e modo escuro
- Layout responsivo para computador e celular

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- LocalStorage

## Objetivo do Projeto

Este projeto foi criado para praticar desenvolvimento front-end, manipulação do DOM, criação de interfaces responsivas e uso de armazenamento local no navegador.

Além da parte técnica, a proposta é oferecer uma experiência visual e reflexiva: a pessoa pode abrir o site, receber uma carta do dia e usar o conselho como ponto de reflexão.

## Como Usar

1. Abra o site.
2. Veja a carta do dia.
3. Leia o conselho e a pergunta de reflexão.
4. Use o botão de sorteio livre para tirar outras cartas.
5. Explore o baralho completo na seção de cartas.
